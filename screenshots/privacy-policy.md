# Privacy Policy — moved

The canonical privacy policy for the ZKProofport mobile app lives at:

    docs/legal/privacy-policy.md

It is served straight from GitHub at that path, and that URL is what the
App Store listing (`ios/fastlane/metadata/*/privacy_url.txt`) and
the in-app About screen both point at.

This file used to hold a third, divergent copy. It described Privy as the wallet
authentication provider, which the app has not used for some time.
