# ZKProofport 모바일 앱 개인정보처리방침

**시행일:** 2026년 2월 1일

**최종 수정일:** 2026년 8월 29일

> 이 문서는 영문 개인정보처리방침의 번역본입니다. 두 문서의 내용이 어긋나는
> 경우 영문본이 우선합니다.

## 들어가며

ZKProofport(이하 "당사")는 ZKProofport 모바일 애플리케이션(이하 "앱")을
운영합니다. 이 방침은 앱을 사용하실 때 당사가 정보를 어떻게 다루고 보호하며
처리하는지 설명합니다.

당사는 프라이버시를 핵심 원칙으로 앱을 설계했습니다. 영지식증명은 이용자의
기기에서 생성되며, 서버로 보내는 데이터와 수집하는 데이터를 최소로 줄였습니다.

## 1. 수집하는 정보

### 1.1 지갑 주소

지갑 연결(WalletConnect / Reown AppKit)로 인증하실 때, 지갑 주소는 다음 용도로
쓰입니다.

- 앱 안에서 본인 확인
- 증명 제출의 온체인 검증(해당하는 경우)
- 증명 요청과 완료를 서로 연결

**지갑 주소는 이용자의 기기에만 저장됩니다. 당사 서버에는 저장하지 않습니다.**

### 1.2 증명 요청 데이터

QR 코드나 딥링크로 증명 요청을 받으면, 그 요청을 화면에 보여주기 위해 요청
정보(회로 종류, 입력 항목, 콜백 주소)를 일시적으로 처리합니다. 이 데이터는

- 처리하는 동안 기기에 머무릅니다
- 이용자가 증명 생성을 명시적으로 승인한 뒤에만 릴레이 서버로 전송됩니다
- 통신이 끊겼을 때 다시 이어붙일 수 있도록 릴레이 서버에 최대 5분간 임시로
  보관되었다가 자동으로 삭제됩니다
- 증명이 생성되거나 요청을 거절하면 기기에서 삭제됩니다

### 1.3 증명 생성과 암호학적 데이터

- **영지식증명은 이용자의 기기에서 생성됩니다.** 증명 입력값이나 계산 과정을
  수집하거나 저장하거나 어떤 서버로도 전송하지 않습니다.
- 완성된 증명(암호학적 산출물)만이, 이용자가 제출할 때 릴레이 서버로
  전송됩니다.
- 증명 자체에는 입력한 내용에 관한 개인정보가 담기지 않습니다. 그것이
  영지식증명을 영지식증명이게 하는 성질입니다.

### 1.4 QR 코드 스캔

QR 코드는 기기 안에서 전부 읽고 해석합니다. 당사는

- QR 코드 이미지를 어떤 서버로도 보내지 않습니다
- 어떤 QR 코드를 스캔했는지 기록하거나 추적하지 않습니다
- 스캔 이력을 당사 서버에 저장하지 않습니다

### 1.5 릴레이 서버와의 통신

완성된 증명을 제출하실 때, 다음을 위해 릴레이 서버와 통신합니다.

- 증명과 딸린 정보(회로 종류, 증명 해시, 시각)를 전달
- 제출이 성공했다는 응답을 수신
- 요청한 애플리케이션에 콜백 알림을 전달

릴레이 서버는 통신이 끊겼을 때 다시 이어붙일 수 있도록 증명 결과(증명 데이터,
공개 입력, 널리파이어)를 최대 5분간 임시로 보관했다가 자동으로 삭제합니다.

**이 과정에서 이용자의 신원이나 증명 입력값에 관한 개인정보는 전송되지
않습니다.**

### 1.6 수집하지 않는 정보

당사는 다음을 수집하지 않으며 당사 서버로 전송하지도 않습니다.

- 지갑 주소 (기기에만 저장)
- 증명 입력값 (국가 목록, 어테스테이션 데이터, 서명)
- 증명 데이터 전체 (릴레이에 5분간 임시 보관 후 삭제될 뿐)
- 모바일 앱 이용자의 신원 정보 (이름, 이메일, 전화번호)
- 위치 정보나 기기 식별자
- 기기의 IMEI, IMSI, MAC 주소, 하드웨어 일련번호
- 생체 정보
- 브라우저·앱 사용 분석이나 행동 추적 정보
- 광고 식별자나 앱 간 추적 정보

## 2. 정보를 어떻게 쓰는가

### 2.1 지갑 주소

- **인증**: 앱을 쓰실 때마다 본인 확인
- **증명 검증**: 요청한 애플리케이션이 제출된 증명을 검증할 수 있게 함
- **서비스 제공**: 증명 요청을 이용자에게 전달하고 완성된 증명을 받음

### 2.2 증명과 요청 데이터

- **증명 처리**: 영지식증명의 생성과 제출을 돕기 위해
- **릴레이 통신**: 완성된 증명을 요청자가 지정한 콜백 주소로 전달하기 위해
- **요청 검증**: 화면에 보여주기 전에 요청이 유효한지 확인하기 위해

### 2.3 통계 데이터

당사는 개인을 알아볼 수 없게 합쳐진 통계(예: 전체 증명 생성 수, 회로 종류별
분포)를 다음 목적으로 분석할 수 있습니다.

- 서비스 개선
- 기술적 문제 해결과 안정성 확인
- 용량 계획

**이 분석은 개별 이용자를 특정하지 않으며 제3자에게 제공하지 않습니다.**

## 3. 데이터 보관

### 3.1 기기 안 보관

앱은 다음을 이용자의 기기에 보관합니다.

- 지갑 주소
- 증명 이력 (증명 해시, 회로 종류, 상태, 시각)
- 증명 생성 기록 (이용자가 확인할 수 있도록)
- 앱 설정 (테마, 언어)
- 지갑 연결 상태

**앱에 들어 있는 내보내기·지우기 기능으로 언제든지 이 데이터를 가져가거나 지울
수 있습니다.**

### 3.2 서버 보관

앱과 요청 애플리케이션 사이에서 증명 요청과 결과를 나르는 릴레이 서버는
**데이터베이스를 두지 않습니다.** 서버가 다루는 모든 것은 쓰는 순간 만료 시각이
붙는 메모리 캐시 안에 있습니다.

| 무엇을 담는가 | 얼마나 | 왜 |
|---|---|---|
| 증명 결과 (증명 데이터, 공개 입력, 널리파이어) | 5분 | 끊긴 연결을 다시 이어붙일 수 있도록 |
| 요청 상태 | 10분 | 요청한 애플리케이션이 결과를 확인할 수 있도록 |
| 요청 세션과 일회용 값 | 10분 | 같은 요청의 재사용을 막기 위해 |

시간이 지나면 항목은 자동으로 지워집니다. 따로 보관해 두는 사본도, 이 항목들의
백업도, 이것들을 다른 곳으로 옮기는 작업도 없습니다.

**당사는 이용자에 관한 영구적인 서버 기록을 남기지 않습니다.** 계정도, 지갑
주소도, 증명 입력값도, 증명 이력도 없습니다. 모바일 앱 이용자에 관한 어떤 것도
위의 10분을 넘겨 남지 않습니다.

### 3.3 이용자의 통제권

이용자는 다음을 할 수 있습니다.

- 앱에 쌓인 증명 이력을 언제든지 지우기
- 증명 이력을 옮길 수 있는 형식으로 내보내기
- 지갑 연결을 끊어 이후의 증명 요청을 받지 않기

지울 계정이 없습니다. 앱의 기기 안 데이터를 지우거나 앱을 삭제하면 당사가 가진
이용자에 관한 모든 것이 사라집니다. 당사가 가진 것이 전부 이용자의 기기에 있기
때문입니다.

## 4. 제3자 서비스

### 4.1 WalletConnect / Reown AppKit (지갑 연결)

지갑 연결은 **WalletConnect** 규약 위에 만들어진 **Reown AppKit** 이 담당합니다
(walletconnect.com). 이 서비스는

- 앱과 이용자의 외부 지갑(MetaMask, Trust Wallet 등) 사이의 통신을 이어줍니다
- 지갑 서명 요청을 전달하는 역할만 합니다
- 개인정보처리방침: https://walletconnect.com/privacy

**지갑은 개인키를 ZKProofport 에 노출하지 않습니다. 모든 서명은 이용자의 지갑
앱 안에서 이루어집니다.**

### 4.2 Microsoft Entra ID (업무 이메일 도메인 증명)

업무 이메일 주소의 소유를 증명하기로 선택하시면, 앱은 **Microsoft Entra
ID**(옛 Azure AD)를 통해 로그인시킵니다. 이 과정에서

- Microsoft 가 본인 확인을 하고 서명된 OIDC 신원 토큰을 돌려줍니다
- 앱은 확인된 이메일에서 도메인 부분만 읽어 증명을 만듭니다
- 증명은 도메인을 밝힐 뿐, 이메일 주소나 이름이나 디렉터리 정보는 밝히지
  않습니다
- 로그인 과정에서 Microsoft 가 하는 처리는 Microsoft 의 개인정보처리방침을
  따릅니다: https://privacy.microsoft.com/privacystatement

**이 과정은 선택입니다.** 업무 도메인 증명을 시작할 때만 실행되며, 하지 않아도
앱의 다른 기능에는 아무 영향이 없습니다.

### 4.3 제3자 검증 서비스

증명 요청을 승인하시면, 요청한 애플리케이션(dApp)이 그 증명을 스스로 검증에
제출할 수 있습니다. 온체인 검증은 요청한 애플리케이션이 수행하며 ZKProofport 가
하지 않습니다. ZKProofport 는 어떤 블록체인 거래나 가상자산 이전도 시작하거나
처리하거나 중개하지 않습니다.

### 4.4 콜백 서비스

증명 요청을 승인하시면 완성된 증명이 요청한 애플리케이션이 지정한 콜백 주소로
전달됩니다. ZKProofport 는

- 받는 쪽 서비스를 통제하거나 감시하지 않습니다
- 콜백을 받는 곳의 개인정보 처리에 대해 책임지지 않습니다
- 요청한 애플리케이션의 개인정보처리방침을 확인하시기를 권합니다

## 5. 데이터 보안

### 5.1 기기 안 보안

- **암호화**: 기기에 저장된 데이터는 iOS·안드로이드의 자체 암호화(iOS 키체인,
  안드로이드 키스토어)로 보호됩니다
- **루팅 불필요**: 기기의 루트 권한이나 탈옥을 요구하지 않습니다
- **기기 안 계산**: 모든 증명 계산은 mopro 라이브러리를 써서 이용자의 기기에서
  이루어집니다

### 5.2 서버 보안

- **전송 구간 암호화**: 모든 서버 통신에 TLS 1.3 을 씁니다
- **저장할 것이 없음**: 릴레이는 데이터베이스를 두지 않습니다. 서버가 가진
  사본은 3.2 절의 만료되는 캐시 항목뿐이며, 시간이 지나면 사라집니다
- **접근 통제**: 서버 접근은 역할에 따라 권한을 받은 담당자로 제한됩니다
- **운영 기록**: 릴레이는 안정성과 보안 확인을 위해 요청이 있었다는 사실을
  기록합니다. 증명 데이터는 그 기록에 들어가지 않습니다. 증명은 앞뒤 몇 글자만
  남기고, 공개 입력은 개수만 적은 뒤에 기록됩니다
- **증명 데이터 없음**: 서버는 증명 입력값이나 계산 과정을 저장하지 않습니다

### 5.3 당사가 막을 수 없는 것

다음에 대해서는 안전을 보장할 수 없습니다.

- 기기의 분실
- 기기에 설치된 악성 프로그램 (당사가 통제할 수 없음)
- 지갑 개인키의 유출
- 이용자가 통제하지 않는 지점에서의 통신 가로채기 (콜백을 받는 쪽)

## 6. 어린이의 개인정보

ZKProofport 앱은 만 13세 미만 어린이를 대상으로 하지 않습니다. 당사는 만 13세
미만 어린이의 정보를 알면서 수집하지 않습니다. 만 13세 미만 어린이의 정보를
수집했다는 사실을 알게 되면 그 정보를 즉시 삭제합니다. 함께 닫을 계정은
없습니다. 3.3 절에서 밝힌 대로 앱은 계정을 만들지 않습니다.

부모나 보호자로서 자녀가 ZKProofport 에 정보를 제공했다고 생각되시면
support@masselabs.com 으로 연락해 주십시오.

**이 앱을 쓰려면 만 13세 이상이어야 합니다(이용자가 속한 관할에서 정한 디지털
성년 연령이 그보다 높다면 그 연령).**
