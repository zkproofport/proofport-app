ZKProofport 1.3.1 (build 9) is an on-device zero-knowledge proof generation app.

CRYPTOCURRENCY AND THE WALLET

No cryptocurrency buying, selling, swapping, trading or transfers are provided.
There is no Trade tab or trading page. The main navigation is Verify, Wallet,
the QR scanner, History and More.

Reown AppKit / WalletConnect connects an existing external wallet. For
wallet-based proofs, the user approves a message signature (personal_sign) to
demonstrate control of the wallet. This is not a cryptocurrency transaction or
asset-transfer authorization. No embedded wallet or custody is provided;
private keys remain in the external wallet.

The app reads existing public attestations and can check proofs with a
read-only verifier contract call. It does not submit blockchain transactions
or spend gas. Coinbase references concern existing identity attestations, not
Coinbase trading or exchange functionality.

PURPOSE AND PROOF FLOW

A compatible dapp can request a proof through our SDK. The app opens the
request and generates the proof locally on the device. The finished proof and
its public verification inputs return to the requesting dapp through the
relay. Private proof inputs are not sent to that dapp. The dapp may verify the
proof on-chain or off-chain. The Verify tab also supports standalone proving.
There is no remote proving server or AI service in this app.

Supported proofs:
- Coinbase KYC: possession of an existing Coinbase identity attestation.
- Coinbase Country: whether the attested country satisfies a country-list
  inclusion or exclusion requirement.
- OIDC Domain: an email-domain fact without disclosing the full email address
  to the requesting service.

HOW TO TEST

OIDC Domain requires no wallet or Coinbase attestation:
1. In Verify, change the network picker from Base to Other.
2. Select OIDC Domain.
3. Leave Domain to prove empty and keep the default Scope.
4. Choose Any Email as the verification mode.
5. Select Sign in with Google and use an ordinary personal Google account.
6. Follow the on-device proof generation progress.

The Coinbase entries under Base require a wallet that already holds the
corresponding Coinbase attestation. A new wallet without it cannot complete
these proofs. The review recording demonstrates all three proof flows.

NETWORK USE

- WalletConnect: external wallet communication and message signing.
- Public Base RPC providers and base.easscan.org: attestation queries.
- Google / Microsoft: supported identity sign-in.
- GitHub: download public proving circuits and keys, checked before use.
- relay.zkproofport.app: return a completed proof for a dapp-originated request.
- Configured RPC endpoints: read-only proof verification.

There is no analytics, crash-reporting or advertising SDK.

ACCOUNTS, PURCHASES AND REGIONS

No ZKProofport account, registration or password is created. External sign-in
uses an existing identity-provider account. No in-app purchases, user posts,
comments or messaging are provided. Features are identical across regions;
the user can choose the interface language.

History > Clear All removes saved proof records. More > Clear Local Data
clears local app data. More > Export Proof History exports the saved records.
