ZKProofport는 요청 서비스에 민감한 원본 정보를 직접 공개하지 않고 신원에 관한 사실을 입증할 수 있도록 영지식증명(ZK 증명)을 생성하는 앱입니다.

앱은 증명 생성과 검증을 위한 도구이며, 암호화폐 매수·매도·교환·거래·전송 기능을 제공하지 않습니다.

주요 기능

기기에서 증명 생성
Noir 회로와 mopro 라이브러리를 사용하여 기기에서 직접 증명을 계산합니다. 원격 증명 생성 서버가 필요하지 않습니다.

Coinbase KYC 증명
요청 서비스에 자격 증명 지갑 주소나 KYC 신원 정보를 직접 공개하지 않고, 기존 Coinbase KYC 증명을 보유하고 있음을 입증합니다. Base에서 Coinbase 증명을 이미 보유한 지갑이 필요합니다. ZKProofport가 Coinbase의 신원 확인을 수행하거나 Coinbase 거래 기능을 제공하는 것은 아닙니다.

Coinbase 국가 증명
요청 서비스에 자격 증명 지갑 주소나 신분증을 직접 공개하지 않고, Coinbase 증명에 기록된 국가가 지정된 국가 목록의 포함 또는 제외 조건을 충족하는지 입증합니다.

OIDC 도메인 증명
지원되는 Google 또는 Microsoft 로그인으로 이메일 도메인에 관한 증명을 생성하며, 요청 서비스에 전체 이메일 주소를 직접 공개하지 않습니다. Verify > Other > OIDC Domain에서 사용할 수 있습니다.

지갑 메시지 서명
WalletConnect로 기존 외부 지갑을 연결합니다. 지갑 기반 증명에서는 지갑을 제어하고 있음을 확인하기 위한 메시지 서명을 승인합니다. 이 서명은 자산 전송을 승인하거나 암호화폐 거래를 실행하지 않습니다. 개인 키는 외부 지갑에 유지됩니다.

증명 검증
기기에서 증명을 검증하거나, 배포된 검증 컨트랙트를 읽기 전용으로 호출하여 결과를 확인합니다. 앱의 컨트랙트 검증은 블록체인 거래를 전송하거나 가스를 지불하지 않습니다. 요청 서비스도 완성된 증명을 독립적으로 검증할 수 있습니다.

QR 코드와 딥링크
호환 서비스의 QR 코드나 딥링크로 증명 요청을 엽니다. 요청을 검토하고 기기에서 증명을 생성한 다음, 완성된 증명을 릴레이를 통해 요청 서비스로 반환합니다.

증명 이력과 화면 설정
저장된 증명 이력을 조회·관리하고 밝은 테마 또는 어두운 테마를 선택할 수 있습니다.

사용 방법

1. Verify를 열거나 호환 서비스의 증명 요청을 엽니다.
2. 증명 종류와 필요한 조건을 확인합니다.
3. Coinbase 증명은 필요한 자격을 보유한 지갑을 연결하고 메시지 서명을 승인합니다. OIDC 증명은 지원되는 로그인 절차를 사용합니다.
4. 기기에서 영지식증명을 생성합니다.
5. 결과를 확인하거나 검증하고, 서비스 요청으로 시작한 경우 완성된 증명을 반환합니다.

프라이버시와 네트워크 사용

영지식증명은 서비스가 비공개 증명 입력값을 받지 않고 요청한 사실을 검증하도록 합니다. 앱은 외부 지갑 통신, 지원되는 신원 제공자 로그인, 공개 증명 기록 조회, 회로 다운로드, 완성된 증명 전달 및 검증을 위해 네트워크를 사용합니다. 완성된 증명에는 검증에 필요한 공개 입력값이 포함됩니다.

QR 스캐너를 사용할 때 카메라 접근 권한을 요청합니다.
