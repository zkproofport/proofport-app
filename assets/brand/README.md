# ZKProofport brand assets

Copied unchanged from the brand kit (version 2026-10-13) kept in the parent
repository at `docs/design/zkproofport-brand-kit/`. Read its
`brand-guidelines.txt` before using them.

- `zkproofport-symbol.png` — the shield and anchor, 600 × 600.
- `zkproofport-wordmark-dark.png` — wordmark for dark backgrounds (paper suffix).
- `zkproofport-wordmark-light.png` — wordmark for light backgrounds (navy suffix).

Show the wordmark at 160 px wide or larger, and the shield at 32 px tall or
larger. Code takes them from `src/constants/brand.ts`, never by path.
